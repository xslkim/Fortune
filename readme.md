# 渲染原理

## 流程

因为要支持半透明，为了防止边和面相接的地方发生交叉重叠，用Stencil buffer过滤掉重叠的部分。只有后画的Stencil Ref值高于先画的时候，才允许叠加。

用Material.renderQueue控制画的顺序，将点线面按背面、正面和外轮廓分组。顺序如下

1. 置顶的点。 _StencilRef = 4
2. 置顶的边。 _StencilRef = 4
3. 背面的点。 _StencilRef = 1
4. 外轮廓线上的点。可以与背面的点叠加 _StencilRef = 2
5. 外轮廓线的边。可以与背面的点叠加 _StencilRef = 2
6. 背面的边。 _StencilRef = 1
7. 背面的面。 _StencilRef = 1
8. 正面的点。可以与背面和外轮廓的元素叠加 _StencilRef = 3
9. 正面的边。可以与背面和外轮廓的元素叠加 _StencilRef = 3
10. 正面的面。可以与背面的元素叠加 _StencilRef = 2

## 实现

边用Unity内置的Capsule模型。用vertex shader调整长度粗细。先缩短成球形，再缩放调整粗细，然后旋转，再拉长。虚线效果是用fragment shader根据到一端的距离裁剪。

点用Unity内置的球体，缩放移动。

面用程序生成Mesh，每个面对应一个SubMesh。由Unity计算生成normal以支持光照。

边和点需要区分属于背面、正面或外轮廓。根据相邻的面的法线与视线的关系判断。

1. 所有面背对视线的是背面。
2. 所有面正对视线的是正面。
3. 有背对有正对的是外轮廓线。

在shader中判断，不该显示时把顶点放在裁剪空间外。不在c#中判断的原因是可能有多个摄像机，视线方向不同。

# 几何体构成

1. 几何体由点和面创建。

2. 每个点对应一个坐标值。

3. 每个面包含多个三角形。每个三角形有3个顶点索引，面对镜头时成顺时针的顺序。

4. 边根据面的信息自动生成，每条边由两个顶点索引构成。每条边的两侧各有一个三角形。边在内部处理时是有方向的，分成正反两条边，分别记录一侧的三角形。

5. 面与面之间的边作为硬边，始终显示。面内部的三角形之间的边作为软边，只有在成为外轮廓线时，或者单独设置了颜色粗细时显示。

6. 点只有在单独设置了大小后才会显示。
